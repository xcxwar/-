Khabarino فارسی 🇮🇷📰

این نسخه برای انتشار فقط اخبار فارسی ساخته شده است.

تغییرات:
- منابع انگلیسی و خارجی حذف شده‌اند.
- فقط RSSهای فارسی داخل SOURCES فعال هستند.
- خبرهای غیر فارسی نیز قبل از انتشار فیلتر می‌شوند.
- هشتگ‌ها خودکار فارسی و متناسب با موضوع خبر ساخته می‌شوند.
- هر خبر می‌تواند تا ۶ عکس مرتبط داشته باشد.
- ویدئوی مرتبط نیز در صورت قابل دریافت بودن ارسال می‌شود.
- رسانه‌های تبلیغاتی، بنر، لوگو و موارد مشکوک فیلتر می‌شوند.
- فاصله بین هر پیام ارسالی ۱۰ ثانیه است.
- خرابی یک رسانه باعث حذف کل خبر نمی‌شود.

تنظیمات:
1) BOT_TOKEN و CHANNEL_ID را در bot.py وارد کن.
2) pip install -r requirements.txt
3) python bot.py
